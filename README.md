# Dogs Bet Owner Panel

Web panel for the owner and cashiers.

## Roles

- **Owner** — bots, users, ShamCash secrets, and prices.
- **Cashier** — dollar rate, deposit/withdraw limits, and withdraw fee only.

## Login (change in production)

- owner / owner123
- cashier / cashier123

Override with `OWNER_PASSWORD` and `CASHIER_PASSWORD`.

## Coolify

- Domain: `wolf.ahmad-zaven.io`
- Port: `8000`
- Env: `SECRET_KEY`, optional `OWNER_PASSWORD`, `CASHIER_PASSWORD`
